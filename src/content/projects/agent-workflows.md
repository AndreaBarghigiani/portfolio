Agent workflows is a collection of reusable development practices for projects with different stacks and boundaries. Projects pin the shared procedures while keeping their own product rules in their repository.

I maintain the workflows and use them to make issue delivery, independent review, and engineering memory more consistent across projects. The system favors scoped changes and evidence that another session can pick up.
